# 仕様

## 目的と完了の条件
- Excel の SPI 言語の問題（488行）を、ブラウザで本番に近い制限時間で解ける。
- 問題が表示されてからの経過秒数を 0.1 秒刻みで常に表示する。残り時間は時限爆弾風のカウントダウンで見せる。
- 最初にパスワード（4桁）を入れないと問題が読めない。

## 画面・機能
- ロック画面: パスワードで data.enc.json を復号する。この端末で記憶する（localStorage）。
- 最初の画面（2026-11-09 に作り直した）: 問題タイプを押して選ぶボタン（問題数、制限秒数、解いた数、累計の正答率つき）。制限時間は折りたたみの中で種類ごとに変える。問題数は 10・20・30・50・すべてと、数字の入力。タイプは本番と同じ順（熟語の意味 → 語句の用法 → 二語の関係 → 二語の関係（組み合わせ） → 空欄補充（短文） → 空欄補充（文章） → 文の並べ替え → 長文読解）に固定し、タイプの中の問題はランダム（既定）か問題集の順（タイプごとに前回の続きから。最初からに戻すボタンあり）で選ぶ。問題数は選んだタイプに均等に分け（余りは前のタイプから）、長文は近い組の数に丸めて最低1組入れ、ずれは1問ずつのタイプで後ろから増減して合計をそろえる。出題する問題（すべて／間違えた／未回答）、答え合わせ（本番・練習）、時間切れで次へ、音。下の帯に、問題数、最大の所要時間、タイプごとの内訳を出す。
- 出題画面（2026-11-09 にテストセンターの画面に寄せて作り直した）: 左上に灰色の帯で設問の指示文、左に本文（下線つき）、右上に時間と回答状況の円グラフ（外側の輪＝全体の制限時間のうち使った割合、内側の輪＝全問題のうち答えた問題の割合。本番と同じく進み具合のメーター。組問題では1問答えるごとに内側が進む）、右の枠に設問と選択肢（丸、すべて選ぶ問題は四角）、左下に回答時間のマス（緑5・黄2・橙2・赤1。時間とともに左から塗られる）と経過秒数、右下にオレンジの次へ。
- 出題中は、画面の下に Chrome の画面共有の帯（exam.excert.org が画面を共有しています。 共有を停止 非表示）の見た目を常に出す。本番の緊張感を出すためで、ボタンは押しても何も起きない。上の進み具合（何問目か、種類）は本番にないので出さない。
- 時間切れ（赤のマスまで塗られる）で自動的に次へ進む。進まない設定では、経過秒数を赤で数え続ける。
- 回答の形: 1つ選ぶ、すべて選ぶ、ア・イ・ウは本番どおり A アだけ〜F イとウ の6択、断片の並べ替え（押した順、数字キー可）、文中から抜き出し（入力）。キーボード A〜H・1〜8・Enter。
- 下線: Excel の注記（下線は「まい」など）、カタカナの語、《》で示された語に引く。印のない用法の問題は、選択肢の半分以上に出てくる最も長い語に引く。印のない熟語の意味の問題は本文全体に引く。
- 長文の3問組（同じ本文が続く行）は、ランダムでもばらさず1つの画面にまとめ、枠の下の 1 2 3 のタブで自分で切り替える。次へで次のタブに進み、最後のタブで次へを押すと組全体の回答が確定する。制限時間は組全体で1つ（各問の秒数の合計。既定は 60 秒 × 3 問 = 180 秒）。
- 結果画面（2026-11-09 に作り直した）: 正答率、正解数、合計と1問あたりの時間、時間切れの数、種類ごとの正答率のバー。その下に1問ずつ、指示文・本文（長い本文は折りたたみ）・選択肢（あなたの答えと正解に札と色）・注記・解説を開いた状態で並べる。すべて／不正解だけ／時間切れだけで絞れる。間違えた問題だけを解き直せる。練習モードの1問ごとの解説も同じカードで出す。

## 既定の制限時間（設定で変えられる。SPI は公式に1問ごとの秒数を公表していないため、本人の指定した 10・30・60 秒を基準に決めた）
| 種類 | 秒 |
|---|---|
| 熟語の意味 | 10 |
| 語句の用法 | 15 |
| 二語の関係 | 10 |
| 二語の関係（組み合わせ） | 20 |
| 空欄補充（短文） | 10 |
| 空欄補充（文章） | 30 |
| 文の並べ替え | 60 |
| 長文読解 | 60 |

## 正解の扱い
- 答え列を正とする。AIの答え列が別の答えのとき（○以外）は、どちらを選んでも正解にし、その旨を解説の上に出す。
- 答え列が空で AIの答えがあるときは、AIの答えで採点する。B or D のような書き方は両方を正解にする。
- 選択肢や断片が欠けている問題（5問）と、答えが該当なしのア・イ・ウの問題（1問。本番の6択にないため）は、採点せず出題からも外す。

## データ（項目、誰が見られるか、保存期間）
- 問題は暗号化して site/data.enc.json に置く（AES-GCM、鍵は PBKDF2-SHA256 で 60万回）。パスワードを知らない人は読めない。ただし4桁なので、暗号文を手に入れた人が総当たりすれば解ける。目的は、たまたま見た人に読ませないこと。
- 回答の履歴と設定は、その端末のブラウザの localStorage にだけ残る。サーバーには送らない。

## やらないこと（範囲の外）
- 非言語（計算）、玉手箱・TG-WEB の問題。
- 複数の端末で履歴を同期すること。
