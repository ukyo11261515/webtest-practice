# 問題セットのデータの形（日付ごとの問題を手元版に足すとき）

2026-11-11 作成。友人と出し合った問題（画面の読み取りの記録）を、練習サイトの問題として整理するときの形。
1つのセットは1つの JSON ファイル（UTF-8）。手元版（build/build_local.py）だけに入れ、公開版（GitHub Pages）には入れない。

## ファイル全体
```json
{
  "set": "20261111",
  "label": "11月11日",
  "items": [ ...問題、または既存の問題への参照... ],
  "excluded": [ {"xlsx_no": [15, 16], "reason": "練習サイト自体の画面の読み取りで、設問がない"} ]
}
```

## 既存の問題への参照
SPI 問題集（out/questions.json）と同じ問題は、新しく作らずに参照だけを置く。
```json
{"ref": "r21", "xlsx_no": [182, 202], "ocr": ["20261110-xxxxxx-xxx.md"]}
```
同じ問題とは、本文と選択肢が実質同じ（読み取りの崩れ、句読点の , と、の違いは無視）こと。

## 新しい問題
```json
{
  "id": "s1111-012",
  "type": "nv_table",
  "mode": "single",
  "passage": "ある書店で来店客100人にアンケートを行った。表はその結果の一部である。",
  "tables": [
    {"caption": null, "rows": [["項目", "はい", "いいえ"], ["甲について", "70人", "30人"]], "header_rows": 1}
  ],
  "after_table": "甲と乙の両方に「はい」と答えた人は50人だった。",
  "prompt": "甲だけに「はい」と答えた人は何人か。",
  "optionKind": "letter",
  "options": [{"key": "A", "text": "10人"}, {"key": "B", "text": "20人"}, {"key": "C", "text": "AからBのいずれでもない"}],
  "accepted": [["B"]],
  "unit": null,
  "scored": true,
  "explanation": "甲に「はい」の70人から、両方に「はい」の50人を除くと、70 − 50 = 20人。",
  "notes": [],
  "group": "s1111-g03",
  "ai_majority": "20人",
  "ai_agreement": 0.5,
  "xlsx_no": [1],
  "ocr": ["20990101-000000-000.md"]
}
```

### 項目の決まり
- id: `s1111-` に3桁の連番。シートごとに番号の範囲を分ける（単語 001〜299、日本語 301〜599、計算 601〜899）。
  - 出し合いの記録ではなく、本番の入力形式に慣れるために作った練習問題のセットは、`p1111-` のように p で始め、001 からの連番にする（例: 問題セット_20261111p、ラベルは 本番形式の練習（11月11日を参考））。
- type（タイプ）: 下の表から選ぶ。
- mode（答え方）:
  - single: 1つ選ぶ。accepted は `[["H"]]`。正解が2つあり得るときだけ `[["B"],["D"]]`。
  - multi: すべて選ぶ（チェックボックス）。accepted は `[["A","C"]]`。
  - order: 1〜5 の断片を並べ替える。options の key は "1"〜"5"、accepted は `["51243"]`。
  - text: 文中から抜き出して入力。accepted は答えの文字列の配列（例 `["更新"]`）。
  - number: 数値を入力（非言語の入力式）。accepted は数値の文字列の配列（例 `["45"]`）。分数の答えは `["7/16"]` の形（約分した形）。unit に単位（例 "人"、"円"、"%"）を入れる。
- optionKind: letter（A, B, …）、kana（ア・イ・ウの組み合わせの問題）、digit（並べ替えの 1〜5）。
- passage: 本文。表の前の文。読み取りの崩れ（誤字、改行の混入、画面の部品の文字、時間の表示、URL のような文字列）は直す。直せない箇所は notes に書く。
- tables: 表があるときだけ。読み取りの HTML の表を、行ごとのセルの配列にする。header_rows は見出しの行数。
- after_table: 表の後ろの文（なければ省く）。
- prompt: その設問の問い（例「［2］にあてはまるものはどれか」「何人か」）。
- 組問題（同じ本文で2〜4問）: 本文・表は各問に同じものを入れ、group を同じにし、ファイルの中で続けて並べる。prompt に「（2問組の1問目）」のような順番を入れる。
- explanation: 解き方と根拠。非言語は式と計算の途中を必ず書く。言語・英語は本文や語の意味の根拠を短く。です・ます調ではなく、既存の解説と同じ常体で、短く。
- scored: 正解に確信が持てるときだけ true。問題文や選択肢が欠けて解けないものは items に入れず excluded に回す。
- ai_majority / ai_agreement: Excel の最多回答と一致率（そのまま写す）。
- notes: 読み取りの補い（例「選択肢 F〜H は読み取りが欠けていたため、同じ問題の別の読み取りから補った」）や、AI の多数決と正解が違う場合（「AI の多数決は 30人だが、計算では 20人」）。

## タイプ（type）
| type | 名前 | 区分 | 既定の秒数 |
|---|---|---|---|
| meaning | 熟語の意味 | 言語 | 10 |
| usage | 語句の用法 | 言語 | 15 |
| pair | 二語の関係 | 言語 | 10 |
| pair_combo | 二語の関係（組み合わせ） | 言語 | 20 |
| blank_short | 空欄補充（短文） | 言語 | 10 |
| blank_passage | 空欄補充（文章） | 言語 | 30 |
| order | 文の並べ替え | 言語 | 60 |
| reading | 長文読解 | 言語 | 60 |
| nv_inference | 推論 | 非言語 | 90 |
| nv_combo | 場合の数・確率 | 非言語 | 60 |
| nv_ratio | 割合・損益算 | 非言語 | 60 |
| nv_table | 表・資料の読み取り | 非言語 | 90 |
| nv_calc | その他の計算 | 非言語 | 60 |
| en_vocab | 英語の語彙 | 英語 | 15 |
| en_fill | 英語の空欄補充 | 英語 | 20 |
| en_rewrite | 英文の書き換え | 英語 | 45 |
| en_reading | 英語の長文 | 英語 | 60 |
